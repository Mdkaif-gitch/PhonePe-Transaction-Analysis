# PhonePe Transaction Analysis Dashboard

## Project Overview
This project is an interactive Power BI dashboard designed to analyze PhonePe transaction data and generate meaningful business insights.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization

## Key Features
- Total Transactions Analysis
- Total Transaction Value
- Unique Users Analysis
- Successful Transaction Rate
- Payment Status Analysis (Failed, Pending, Successful)
- Transactions Over Time
- Age Segment Contribution
- Service Transaction Value Analysis
- Top 5 Users by Transaction Value
- Weekday vs Weekend Usage

## Key Insights
- Analyzed transaction performance and payment status.
- Identified popular services based on transaction value.
- Compared weekday and weekend transaction activity.
- Explored user age segments and transaction patterns.

## Project Objective
To transform raw transaction data into meaningful insights through interactive visualizations and help understand payment trends and user behavior.
